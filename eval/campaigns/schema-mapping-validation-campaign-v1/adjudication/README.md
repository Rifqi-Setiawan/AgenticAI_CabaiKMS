# Adjudication outputs

This directory is intentionally empty of human decisions. After both completed round-1 workbooks are validated and frozen, the agreement command in `docs/annotation_campaign_runbook.md` creates `disagreements_round1.xlsx` here. After human adjudication, the documented finalization command creates the final strict gold workbook and immutable decision history here.

Do not prepopulate or infer adjudication from system predictions.
