4. HASIL OLAHAN SISTEM (4_hasil_sistem/)
=====================================================================
Setiap folder run berisi:
  hasil_kanonik.xlsx      spreadsheet terstandar keluaran sistem (Sheet1; Sheet2/Sheet3 kosong bawaan template).
                          Baris = 60 karakter kanonik, kolom = varietas dari input. Baris 57-60 berisi tautan
                          Google Drive foto yang ditautkan otomatis (AUTO_LINK).
  pemetaan_atribut.csv    keputusan pemetaan per atribut sumber (baris target, confidence, alasan model,
                          metode exact-name/retrieve-rerank, status verifier, AUTO_ACCEPT/REVIEW).
  klasifikasi_foto.csv    hasil klasifikasi per foto (status KNOWN/OTHER/UNCERTAIN, varietas, bagian
                          tanaman, confidence, bukti visual, ditulis atau tidak).
Semua run dijalankan lewat antarmuka web Streamlit produksi (bukan skrip), diunduh dengan tombol unduhan UI.
Model: teks ag/gemini-3.8-flash-medium, vision ag/gemini-3.8-flash-high (lewat gateway 9Router);
embedding paraphrase-multilingual-MiniLM-L12-v2. Hasil ini adalah keluaran mentah sistem SEBELUM koreksi
kurator (tidak ada item review yang disetujui/direvisi).
